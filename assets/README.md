# assets

Static image assets used by report_generator.py.

- `bentley-wings-green.png` — Bentley wings logo, dark green on transparent
  background. Used on the cover page (large, centred) and in the header of
  every subsequent page (small). Save the provided "Bentley Wings Logo (dark
  green, transparent).png" here under this exact filename.

The white-on-transparent variant isn't used in reports (report pages stay
white background throughout), so it doesn't need to go here.
